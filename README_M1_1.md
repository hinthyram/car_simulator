# Car Simulator V6.7 — Map System M1.1

이번 버전은 **V6.7 물리엔진을 기준으로 유지**합니다. V6.8 토크 HUD 변경은 포함하지 않습니다.

## 폴더 구조

- `index.html` — 홈페이지 / 맵 선택
- `simulator/` — 차량 시뮬레이션 전용
- `map-editor/` — 맵 제작 전용
- `shared/` — 향후 공통 맵 데이터/유틸리티를 넣을 공간

## M1.1에서 고친 문제

기존 맵 에디터가 아무 동작도 하지 않았던 원인은 `roadMode`라는 **버튼의 DOM id와 boolean 상태 변수 이름이 충돌**했기 때문입니다. 스크립트가 초기화 중 `roadMode.onclick`에서 중단되어 나머지 기능도 등록되지 않았습니다.

이번에는:
- `isRoadMode`를 상태 변수로 분리
- 버튼은 `roadModeBtn`, `roadEndBtn` 등으로 명시적으로 가져옴
- 저장/테스트 주행/지형 편집/도로 편집 이벤트를 모두 다시 연결

했습니다.

## 실행

Three.js ES module을 사용하므로 가능하면 로컬 HTTP 서버로 실행하세요.

예:
`python -m http.server 8000`

그 다음 브라우저에서 `http://localhost:8000/` 접속.
