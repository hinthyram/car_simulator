# Car Simulator V6.7 — Map System M2

기준 버전: V6.7. 차량 물리엔진은 유지하고 맵 시스템만 확장했습니다.

## 이번 버전

### 1. 맵 관리
- 홈페이지에서 사용자 맵 목록 확인
- 주행 / 수정 / 삭제
- 수정 화면에서 기존 맵을 그대로 불러오기
- `shared/mapStorage.js`로 저장 계층을 분리
- 현재는 localStorage, 향후 서버 API로 교체할 수 있는 구조

### 2. 3D 맵 에디터
- 기본 3D 시점
- OrbitControls로 회전/확대/축소
- 탑뷰 전환
- 타일 클릭 기반 편집
- 높이 편집

### 3. 타일 기반 맵
도로 중심선을 찍는 방식은 제거하고 맵을 타일로 구성합니다.

기본 타일:
- 아스팔트 μ 0.95
- 콘크리트 μ 0.90
- 자갈 μ 0.65
- 흙 μ 0.55
- 잔디 μ 0.40
- 얼음 μ 0.15

차량 물리에서는 각 바퀴의 접촉 위치를 기준으로 해당 타일의 마찰계수를 TireModel에 전달합니다.

### 4. 맵 크기
맵 폭/길이와 타일 크기를 지정하고 `적용`을 누르면 실제 타일 개수와 맵 크기가 다시 생성됩니다.
현재 맵 크기는 타일 크기의 배수로 맞춰집니다.

## 폴더
- `index.html`: 홈페이지/맵 관리
- `map-editor/`: 맵 제작
- `simulator/`: 차량 시뮬레이터
- `shared/`: 공통 저장/데이터 계층
- `docs/`: 기존 문서

## 실행
ES module/Three.js를 사용하므로 로컬 HTTP 서버를 권장합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/` 접속.
